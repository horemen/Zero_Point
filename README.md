# Zero Point

Пиксельная браузерная RPG. Героиня Аэлис сама охотится в Звериных лугах на зверей, птиц, гуманоидов и элементалей, собирает добычу и продаёт её за коины, погибает, воскресает в деревне и снова идёт в бой. Игрок выбирает оружие и изучает навыки в паутине.

Играть: https://crashic.github.io/Zero_Point/ (можно установить на Android как приложение).

## Структура
- `index.html` — разметка интерфейса и подключение скриптов
- `css/style.css` — оформление
- `js/` — по файлу на функцию: настройки, сохранение, характеристики, владение, мир, земля, враги, бой, ИИ героини, отрисовка, окна интерфейса, установка
- `sprites/` — спрайты (героиня, звери, окружение) и иконки приложения
- `manifest.webmanifest`, `sw.js` — установка на телефон и работа без интернета

Версия: 0.3.0.2
